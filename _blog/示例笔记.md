这里是课外学习笔记。和作业一样，开头只需要三行：

```markdown
---
title: 笔记标题
---
```

## 文件名怎么起

随便起。`_blog/` 里的笔记**按文件名倒序**排列，所以想让新笔记排在前面，在文件名前加个靠后的标识就行，比如：

```
_blog/2026-10-25-读某本书.md
_blog/2026-10-20-某个想法.md
```

加了日期前缀就自然形成"新的在上"，不加也不影响，只是顺序按字母走。

## 和作业的区别

| | `_homework/` | `_blog/` |
|---|---|---|
| 首页位置 | 「课程作业」栏 | 「学习笔记」栏 |
| 排序 | 文件名正序（01、02…） | 文件名倒序 |
| 用途 | 交给老师看的 | 自己写、别人看的 |

两边的排版、配色、上一篇/下一篇导航完全一样。
